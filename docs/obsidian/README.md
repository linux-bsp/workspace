# SadBoard Obsidian 手册

在 Obsidian 中选择“打开文件夹为仓库”，打开本目录下的 **`sadboard/`**，然后阅读 [首页](sadboard/首页.md)。不要将整个 `docs/` 作为此仓库的根目录。

- [学习导航](sadboard/学习导航.md)：按章节学习，练习任务、工具参数、内核流程、反汇编分别维护。
- [案例索引](sadboard/案例索引.md)：35 个基础案例和 24 个进阶案例。
- [工具索引](sadboard/工具索引.md)：按调试工具跳转到参数、采集步骤及适用边界。
- [仓库使用说明](sadboard/仓库使用说明.md)：笔记约定、源码链接、个人报告与维护方法。

全部学习内容直接在 Obsidian 笔记中维护。在 SadBoard 工作区根目录运行以下命令，检查双链、目标标题、案例数量和源码路径：

```sh
python3 scripts/check-obsidian.py
```

原始实机验收仍维护在 [AM625 实机验收档案](../am625-debug-validation.md)。本次仅调整文档组织，没有修改设备固件或重新执行硬件实验。
