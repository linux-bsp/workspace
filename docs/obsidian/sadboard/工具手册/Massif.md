## 解决的问题

分析堆分配随工作推进的变化、峰值和主要分配调用栈。

## 工作原理与准备

Massif 是 Valgrind 的堆分析器。它记录分配快照及调用树，回答哪些分配形成高峰；是否泄漏仍需结合所有权与 Memcheck。

## 参数与结果解释

| 参数/字段 | 含义与判断方法 |
| --- | --- |
| `--tool=massif` | 选择堆分析器。 |
| `--massif-out-file=FILE` | 保存专属原始快照。 |
| `--time-unit=B` | 以累计分配/释放字节作为进度，便于比较不同速度的运行。 |
| `ms_print FILE` | 将快照解码为文本曲线及调用树。 |

## 操作步骤

设备端：把当前可写结果根目录保存在本终端，后续路径使用同一变量。

```sh
R=$(sadboard results)
```

设备端：对同一个小负载生成堆快照；这是独立的工具练习，不用于原生性能基线。

```sh
valgrind --tool=massif --time-unit=B --massif-out-file="$R/massif.out" /usr/libexec/sadboard/memory-fixed 4 0
```

设备同一终端：解码刚保存的快照，检查峰值位置和分配栈；在主机分析时先将路径替换为共享目录中的实际文件。

```sh
ms_print "$R/massif.out"
```

## 判断边界

堆快照不是进程 RSS，也不直接包含页缓存、内核缓冲和所有映射。比较两版时保持相同输入与分配次数，并保存原始文件。
