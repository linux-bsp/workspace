# ss

[[首页]] · [[工具索引]] · [[案例索引]]

## 解决的问题

观察现存 socket 的状态、队列和 TCP 内部指标。

## 工作原理与准备

它是快照观察，常与 [[工具手册/tcpdump]] 的时间序列和 iperf JSON 配合；连接已结束时快照可以为空。

## 参数与结果解释

| 参数/字段 | 含义与判断方法 |
| --- | --- |
| `-t` | 选择 TCP socket。 |
| `-i` | 显示 TCP 内部信息。 |
| `-n` | 保留数值地址与端口，避免名称解析。 |
| `RTT/rttvar` | 当前平滑往返时间及其变化估计。 |
| `cwnd/retrans` | 拥塞窗口与重传相关状态，需结合时间和方向。 |

## 操作步骤

设备端：替换本次仍存活的实验命名空间，查看 TCP 状态。

```sh
ip netns exec LEFT ss -ti
```

## 判断边界

`ss -ti` 中 RTT、rttvar、cwnd、retrans 等属于 TCP 状态观察值，不是全链路根因结论。
若短流已结束，快照为空是可能的；pcap 和完整 iperf JSON 仍应保留。
