# procfs

[[首页]] · [[工具索引]] · [[案例索引]]

## 解决的问题

读取进程 FD、资源限制、线程状态和全局内存等现场信息。

## 工作原理与准备

/proc 是内核导出的运行状态接口，数值和对象均有时间窗口。一个进程结束后对应目录消失；PID 可重用，因此须同时记录 boot ID、程序与采集时刻。

## 参数与结果解释

| 参数/字段 | 含义与判断方法 |
| --- | --- |
| `/proc/PID/limits` | 实际继承的限制，例如 RLIMIT_NOFILE。 |
| `/proc/PID/fd` | 描述符编号及引用目标；目录数量本身不足以判定泄漏。 |
| `/proc/PID/status` | 进程与线程、内存等状态字段。 |
| `/proc/meminfo` | 系统全局内存构成，不等于某个 cgroup 的余量。 |
| `/proc/PID/task/TID/wchan` | 线程内核等待点，可能受权限和符号可见性限制。 |

## 操作步骤

设备端：在本终端把 pid 设置为自己的实际实验 PID 后读取资源限制。

```sh
cat /proc/$pid/limits
```

设备端：尽快读取同一 PID 的 FD 引用目标，与稍后快照比较。

```sh
ls -l /proc/$pid/fd
```

设备端：查看全局内存作为背景信息。

```sh
cat /proc/meminfo
```

## 判断边界

读取者也是一个进程；目标内部自己开目录检查与外部读取的资源影响不同。字段单位、共享页和时序要分别解释，不能把 VmSize 直接等同 RSS 或泄漏。
