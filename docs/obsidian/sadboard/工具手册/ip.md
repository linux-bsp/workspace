# ip

[[首页]] · [[工具索引]] · [[案例索引]]

## 解决的问题

检查接口、地址、路由与实验 namespace，确认流量经过哪个对象。

## 工作原理与准备

网络 namespace 隔离网络对象；cgroup 负责资源预算。名称、引用、进程和 veth 是不同生命周期对象，停止进程不等于删除命名 namespace。

## 参数与结果解释

| 参数/字段 | 含义与判断方法 |
| --- | --- |
| `netns list` | 列出现存命名空间。 |
| `-n NAME addr/route` | 在指定 namespace 中查看接口地址或路由。 |
| `netns exec NAME COMMAND` | 在该网络上下文运行观测工具。 |
| `netns add/del NAME` | 创建/删除自己拥有的命名空间，检查重名与清理结果。 |

## 操作步骤

设备端：查看现存 namespace，先核对本例创建的名称。

```sh
ip netns list
```

设备端：只读核对本例地址，LEFT 替换为实际名称。

```sh
ip -n LEFT addr
```

设备端：核对同一个 namespace 的路由。

```sh
ip -n LEFT route
```

## 判断边界

run.info 中的实验标识、namespace、veth 和采集 PID 应属于同次现场。实验完成后只删除自己创建的资源；完整生命周期由 [[工具手册/sadboard]] 管理。
