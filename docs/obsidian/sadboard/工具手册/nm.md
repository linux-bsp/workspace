# nm

[[首页]] · [[工具索引]] · [[案例索引]]

## 解决的问题

查找符号的链接地址、类型和大小，为反汇编及地址换算提供边界。

## 工作原理与准备

同名源码函数可能被内联、优化或去除；符号表与运行装载地址不是同一回事。

## 参数与结果解释

| 参数/字段 | 含义与判断方法 |
| --- | --- |
| `-n` | 按地址排序。 |
| `-S` | 显示可获得的符号大小。 |
| `-C` | 解释 C++ 修饰名；本项目主要使用 C。 |

## 操作步骤

主机端：读取同次构建的符号顺序与大小。

```sh
output/am625-debug-systemd/host/bin/aarch64-buildroot-linux-gnu-nm -n -S output/am625-debug-systemd/images/debug/labs/crash-bug
```

## 判断边界

先核对 ELF 身份。PIE/共享库的链接地址不能未经装载偏移换算就当成运行 PC。与 [[工具手册/objdump]] 和 [[工具手册/addr2line]] 联合使用。
