# 修复与验收

**修复与工程取舍。** 限制连接数、收发缓冲区和空闲生命周期，消费跟不上时背压；保留足以满足带宽时延积的窗口，不把全部缓冲减小当作万能节省。

**量化验收与清理。** 相同连接/数据量，峰值在预算内，关闭后可解释地恢复；无业务丢失，管理网络计数不参与实验结论。
