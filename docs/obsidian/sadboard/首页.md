这是 SadBoard 的手册维护入口。使用 Obsidian **打开文件夹为仓库**，选择 `docs/obsidian/sadboard`；从本页开始学习。

## 学习与证据约定

普通案例先复现、提假设、保存原始证据，再阅读参考分析。内核、启动、CMA 实验必须先读共同门禁和恢复操作。所有 shell 命令的相对路径均从 **SadBoard 工作区根目录** 解释，不是从本笔记目录执行。

源码推导、静态反汇编、实机调用栈和实测采样须分别标注。手册中的源码链接固定到迁移时的 Git 提交；分析新固件仍须使用该固件配套的符号和源码。详见 [[00-实验准备与通用方法/01-构建与启动部署#固定源码与实机证据|源码与实机证据]]。

## 阅读与记录

每个案例是一篇完整详解，按现象、练习、定位、内核机制和验收阅读；通用工具参数集中在 `工具手册/`。从案例的“使用工具”跳到手册，也可从工具手册的“使用场景”返回具体定位步骤。

可批量的 setenv/GDB 配置放在同一块；需要判断结果的构建、连接与验收步骤分开。每块前说明执行位置与用途，保持同一终端的目录、变量和退出状态。

使用 [[附录A-实验报告/01-实验报告模板|实验报告模板]] 保存自己的分析，个人记录放到自行创建的 `实验记录/`，默认不提交。维护方法见仓库外层 `docs/obsidian/README.md`。
