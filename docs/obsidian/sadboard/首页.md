# 首页

这是 SadBoard 的手册维护入口。使用 Obsidian **打开文件夹为仓库**，选择 `docs/obsidian/sadboard`；从本页开始学习。

59 个案例已在真实 AM625 验证：35 个基础案例、24 个进阶案例。固件保持 **v0.0.1**，使用内容 SHA256 区分构建；随机多故障与通用自动评分尚未实现。

## 学习与证据约定

普通案例先复现、提假设、保存原始证据，再阅读参考分析。内核、启动、CMA 实验必须先读共同门禁和恢复操作。所有 shell 命令的相对路径均从 **SadBoard 工作区根目录** 解释，不是从本笔记目录执行。

源码推导、静态反汇编、实机调用栈和实测采样须分别标注。手册中的源码链接固定到迁移时的 Git 提交；分析新固件仍须使用该固件配套的符号和源码。详见 [[关于手册]]。
