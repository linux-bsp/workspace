# 现场与原理

**生产现场与现象。** 车载状态线程或机器人控制线程偶发超时，CPU 总负载不高；中优先级计算线程运行时问题显著。

**原理与因果关系。** 等待锁使 H 无法运行，M 可能延迟 L 释放锁。优先级继承让实际锁拥有者继承等待者优先级，不会自动缩短业务临界区，也不能修复死锁。pthread 默认 mutex 不等于 PI mutex。
