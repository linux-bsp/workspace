# 练习任务

[[首页]] · [[09-性能与调度优化/00-章节导航|章节导航]] · [[09-性能与调度优化/A-P07/00-案例导航|本例导航]] · [[案例索引]] · [[工具索引]]

```sh
sadboard run perf-prefault
sadboard verify perf-prefault
# 完成后使用打印的实际目录执行 sadboard check
```

本例为固定有界负载，无额外参数。源码 [suite-performance.c](https://github.com/linux-bsp/sadboard-external/blob/93c81e82acfdf5d54155d1b9bb750e78645d384f/package/sadboard-labs/src/suite-performance.c)；16 MiB 匿名映射明确禁用 THP，比较业务阶段首次触页与初始化预触页。observed 为业务前 mincore 实测非驻留页 4096→0，auxiliary 为业务阶段 minor faults；两版处理相同 4096 页、checksum=172032。

`perf-prefault-{bug,fixed}.out/.trace` 分别保存摘要与原始事件，字段 observed/auxiliary 的含义以上述本例定义为准。摘要、trace 和完成数必须相符。与正常业务输出不同的故障结果会由本例契约明确识别；不能拿最外层退出0证明没有异常。性能题同时保留 cpu_ns/wall_ns，至少三次再评价时序，不只看资源上界或一次漂亮数字。

**实际复现负载。** 16 MiB 匿名映射明确禁用 THP，比较业务阶段首次触页与初始化预触页。observed 为业务前 mincore 实测非驻留页 4096→0，auxiliary 为业务阶段 minor faults；两版处理相同 4096 页、checksum=172032。

**面试/评审追问。** minor fault 为什么不一定读盘？mlock 会不会自动把所有后续 malloc 也锁住？
