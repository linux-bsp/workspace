# 修复与验收

[[首页]] · [[09-性能与调度优化/00-章节导航|章节导航]] · [[09-性能与调度优化/A-P03/00-案例导航|本例导航]] · [[案例索引]] · [[工具索引]]

**修复与工程取舍。** 限制单次回调预算，慢任务放入有容量上限的 worker 队列；优先处理控制请求。保留顺序、一致性、取消语义，避免把队头阻塞改成无限积压。

**量化验收与清理。** 相同慢任务数与控制请求均完成，控制 P99 明显下降，队列峰值受限且退出能回收全部 worker。
