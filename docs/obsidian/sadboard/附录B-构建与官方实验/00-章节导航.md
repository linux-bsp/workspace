# 附录 B：构建扩展与官方实验迁移

本附录补充配置维护、可选诊断内核和官方实验材料；保留 systemd 与 SD A/B 回退能力，
默认调试启动使用前文的 TFTP/NFS 方式。
早期 `output/am625-debug/` 的 SysV/NFS 验证历史归入 [实机验收档案](https://github.com/linux-bsp/workspace/blob/cb2b20ab8d17e68f4782dd96efe5a1253b64f035/docs/am625-debug-validation.md#bootlin-build-history)，
不再用它的禁用产品后处理、全局不剥离符号等旧策略构建当前 OTA。
