# 现场与原理

**生产现场与异常现象。** 跨平台协议原型正常，接入另一款处理器后报文长度变成巨大值并触发分配失败。

**原理与容易误判的地方。** 线上的字节序、整数宽度、结构体填充与对齐必须由协议定义。直接把字节缓冲强制转换成宿主结构可能把端序、padding 和未对齐访问问题叠加。
