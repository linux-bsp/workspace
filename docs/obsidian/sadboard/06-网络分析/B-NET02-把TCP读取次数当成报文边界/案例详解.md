## 现象与原理

**生产现场与异常现象。** 小流量测试正常，上线后出现半条遥测、两条粘在一起或偶发校验失败。

**原理与容易误判的地方。** TCP 提供有序字节流，不保留应用 send 的边界。短读不等于连接错误，返回零才是读端 EOF；完整协议还要处理长度上限和连接中断时的半条消息。

## 练习任务

设备端：运行“把TCP读取次数当成报文边界”故障现场，记录输出中的实际结果目录与异常证据。

```sh
sadboard run net-framing
```

设备端：执行“把TCP读取次数当成报文边界”的参考修复验收，核对终端结论及保存的结果契约。

```sh
sadboard verify net-framing
```

设备端：把路径占位符替换为本次实际现场目录，复核该次运行的证据完整性与验收约束。

```sh
sadboard check /srv/sadboard/实际目录
```

本例固定小负载，无额外参数；全部源文件安装在 `/usr/src/sadboard/src/`。实现入口为 [suite-network.c](https://github.com/linux-bsp/sadboard-external/blob/93c81e82acfdf5d54155d1b9bb750e78645d384f/package/sadboard-labs/src/suite-network.c)，公共调度器为 [suite.c](https://github.com/linux-bsp/sadboard-external/blob/93c81e82acfdf5d54155d1b9bb750e78645d384f/package/sadboard-labs/src/suite.c)。真实 TCP 流先发 3 B，接收者读到前缀后握手允许发送后续 9 B，不依赖随机时序。故障单次 recv 把短读误判为完整消息失败；参考重组 12 B 并校验 8 B 载荷。

现场内 `net-framing-{bug,fixed}.out` 保存结构化度量，`.trace` 保存实际事件/资源计数，stderr/core/Valgrind 文件按案例保留。check 同时核对 trace 与摘要以及本例信号/业务契约，不会仅检查一个 passed 字符串。故障被限制在子进程或私有 namespace；run 返回的是取证控制器退出状态，真实异常信号要查看 observed/auxiliary 和 stderr，不能只看最外层 shell 的 `$?`。

**复现条件与故障注入。** 独立 netns 中发送带长度的两条消息，故意把头和体分多次发送；故障读者假设一次 recv 一条消息，参考版维护累积缓冲和解析状态。 操作前记录版本/构建 ID、boot ID、输入、资源上限和超时。取证对象必须是自己的实验进程，设计卡中的 PID 均指该子进程。

**面试/评审追问。** send 返回全部长度是否表示对端业务已处理？TCP 可靠传输为什么仍需要应用层协议？ 请提交：候选假设、可证伪实验、原始数据、关键源码分支、修复前后对照和未覆盖边界。只给一个参数调整或一个“修好了”的截图不算完成。

## 定位方法

**定位分析流程。** strace -f -e sendto,recvfrom 对比应用调用大小，tcpdump 在私有接口捕获字节序列；不能用“一个包”定义业务帧。 对照上方工具手册逐项说明命令回答了什么问题；信号/退出码、资源计数、业务完成数和时间轴必须能互相验证。优化前后采用同输入，至少保留一次负例，排除“异常只是没有触发”。

## 内核流程与汇编

**内核阅读入口。** [tcp.c](https://github.com/linux-bsp/linux-7.0/blob/1c04c52c72b0e67ad4b5deca464ea70bc6ebb718/net/ipv4/tcp.c)：tcp_sendmsg_locked、tcp_recvmsg_locked；[socket.c](https://github.com/linux-bsp/linux-7.0/blob/1c04c52c72b0e67ad4b5deca464ea70bc6ebb718/net/socket.c)：__sys_sendto、接收分派。先确认用户态接口或信号，再向对应内核分支追踪；这些是本仓库 Linux 7.0 的源码入口，不是已经采集到的动态调用栈。

## 修复与验收

**修复方案与代价。** 定义固定头、长度、版本和校验，循环处理缓冲中的完整帧并保留尾部；不要仅增大 recv 缓冲。

**量化验收与现场恢复。** 任意拆分/合并发送后消息数、顺序和 checksum 一致；截断消息在 EOF 时报告明确错误。 最后停止实验进程，释放私有文件、描述符或 namespace；保存证据再清理，不删除系统日志，不影响管理网络。
