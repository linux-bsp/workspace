**定位分析流程。** strace -f -e signal,sendto,recvfrom,close 记录调用结果；私有接口抓包分辨 FIN/RST，保留应用请求 ID 和重试次数。 对照本章参数表逐项说明命令回答了什么问题；信号/退出码、资源计数、业务完成数和时间轴必须能互相验证。优化前后采用同输入，至少保留一次负例，排除“异常只是没有触发”。
