# 修复与验收

**修复方案与代价。** 构建时递归检查依赖闭包，在真实 AM625 的 RAM 副本实际启动 /init；不要用从另一版 rootfs 拷贝单个 so 的方式形成混合 ABI。

**量化验收与现场恢复。** 缺库故障在真实设备稳定可复现，完整副本可启动；依赖检查在打包阶段拒绝缺失文件。 最后核对恢复启动的固件身份、健康检查与日志归档；不清除系统历史记录。
