**定位分析流程。** 关联最早 stall/lockup 文本、每 CPU 栈、调度事件、最后业务心跳、boot/reset 记录和 pstore；单独的 reset cause 不足以确认具体软件根因。 对照本章参数表逐项说明命令回答了什么问题；信号/退出码、资源计数、业务完成数和时间轴必须能互相验证。优化前后采用同输入，至少保留一次负例，排除“异常只是没有触发”。
