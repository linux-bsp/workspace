# 工具参数与定位

**定位分析流程。** 保存异常前后的完整日志、任务/CPU/上下文、taint 和精确 vmlinux；按 func+offset 解码，不直接把 KASLR 地址当链接地址。 对照本章参数表逐项说明命令回答了什么问题；信号/退出码、资源计数、业务完成数和时间轴必须能互相验证。优化前后采用同输入，至少保留一次负例，排除“异常只是没有触发”。
