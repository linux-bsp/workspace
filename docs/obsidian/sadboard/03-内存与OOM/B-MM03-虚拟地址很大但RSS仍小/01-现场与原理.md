# 现场与原理

**生产现场与异常现象。** 进程 VIRT 增大几十 MiB，被误判成同量物理内存泄漏。

**原理与容易误判的地方。** 地址空间建立、按需缺页、物理页分配和回收是不同阶段。匿名映射可以先只占虚拟范围；读零页和写入私有页还可能走不同路径，因此只看 VIRT 不足以估算驻留工作集。
