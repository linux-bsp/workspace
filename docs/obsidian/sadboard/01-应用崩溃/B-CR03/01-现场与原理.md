# 现场与原理

**生产现场与异常现象。** 图像帧或网络报文的长度计算差一个字节，服务在几秒后 free 时退出，也可能继续运行但结果错误。

**原理与容易误判的地方。** malloc 对象边界通常不是页边界，越界可能仍落在可写映射中。MMU 只看到有效 PTE，无法替应用判断某个 C 对象的长度；延迟崩溃可能由稍后的分配器检查或邻居对象使用触发。
