# 现场与原理

[[首页]] · [[02-文件描述符/00-章节导航|章节导航]] · [[02-文件描述符/B-FD03/00-案例导航|本例导航]] · [[案例索引]] · [[工具索引]]

**生产现场与异常现象。** 升级助手或后台命令退出后，主服务仍阻塞在管道读取，表面像锁死。

**原理与容易误判的地方。** 管道只有在全部写端引用关闭后才返回 EOF。父进程关闭自己的写端并不代表其他进程没有继承它；这种资源生命周期问题可以在没有互斥锁的情况下造成长等待。
