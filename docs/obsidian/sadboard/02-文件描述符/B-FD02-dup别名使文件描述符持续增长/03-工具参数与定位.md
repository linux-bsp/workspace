# 工具参数与定位

**定位分析流程。** strace -f -e openat,dup,dup2,dup3,close；检查 /proc/PID/fd 与 limits，区别“系统文件对象数”与“当前进程描述符数”。 对照本章参数表逐项说明命令回答了什么问题；信号/退出码、资源计数、业务完成数和时间轴必须能互相验证。优化前后采用同输入，至少保留一次负例，排除“异常只是没有触发”。
