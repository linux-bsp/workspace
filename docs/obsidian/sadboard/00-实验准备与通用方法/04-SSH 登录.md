## 0.3 SSH 登录

当前调试配置允许 root 空密码登录，端口为 22：

主机端：通过 SSH 登录设备，按当前调试环境的认证方式连接。

```sh
ssh root@192.168.10.211
```

SadBoard 从 `/data/ssh/host/` 恢复主机密钥；私钥只在设备生成和保存，不进入 Git 或固件包。
需要 scp 传文件时使用 `scp -O`，本镜像没有配置 SFTP 服务。串口/SOL 入口仍保留。
