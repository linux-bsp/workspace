# 修复与验收

[[首页]] · [[11-网络与数据通路优化/00-章节导航|章节导航]] · [[11-网络与数据通路优化/A-N08/00-案例导航|本例导航]] · [[案例索引]] · [[工具索引]]

**修复与工程取舍。** 明确重试预算、指数退避和 jitter，网络恢复后重置退避但限制并发；业务幂等键避免重复操作，日志限速但保留首个与状态变化错误。

**量化验收与清理。** 同样故障/恢复时间线，尝试次数和日志量受限、恢复延迟在预算内，fd 回基线，不重复执行控制命令。
