# 现场与原理

[[首页]] · [[11-网络与数据通路优化/00-章节导航|章节导航]] · [[11-网络与数据通路优化/A-N06/00-案例导航|本例导航]] · [[案例索引]] · [[工具索引]]

**生产现场与现象。** 多核板整体 CPU 没满，一个核却持续忙于收包；增加应用线程收效有限。

**原理与因果关系。** RSS 硬件分流、RPS 软件分流、NAPI poll budget 与应用亲和性共同影响局部热点；单流哈希不一定跨核，软件分流还增加 IPI/缓存代价。
