```sh
sadboard run net-backpressure
sadboard verify net-backpressure
# 完成后使用打印的实际目录执行 sadboard check
```

本例为固定有界负载，无额外参数。源码 [suite-advanced-network.c](https://github.com/linux-bsp/sadboard-external/blob/93c81e82acfdf5d54155d1b9bb750e78645d384f/package/sadboard-labs/src/suite-advanced-network.c)；真实 TCP 接收方启动先等 100 ms，有限发送窗口使 send 阻塞；生产端 64×4 KiB 消息比较无约束队列与 8 条高水位。observed 为实际应用队列峰值，auxiliary 为 TIOCOUTQ 高水位；全部 64 条处理完，checksum=2016。

`net-backpressure-{bug,fixed}.out/.trace` 分别保存摘要与原始事件，字段 observed/auxiliary 的含义以上述本例定义为准。摘要、trace 和完成数必须相符。与正常业务输出不同的故障结果会由本例契约明确识别；不能拿最外层退出0证明没有异常。性能题同时保留 cpu_ns/wall_ns，至少三次再评价时序，不只看资源上界或一次漂亮数字。
