**定位分析流程。** 用 strace -c -e write,writev,fsync 和 perf stat/report；统计实际行数、字节数和文件 SHA256，区分 stdout 串口与普通文件。 对照本章参数表逐项说明命令回答了什么问题；信号/退出码、资源计数、业务完成数和时间轴必须能互相验证。优化前后采用同输入，至少保留一次负例，排除“异常只是没有触发”。
