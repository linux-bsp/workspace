# 现场与原理

[[首页]] · [[04-CPU性能与火焰图/00-章节导航|章节导航]] · [[04-CPU性能与火焰图/B-CPU02/00-案例导航|本例导航]] · [[案例索引]] · [[工具索引]]

**生产现场与异常现象。** 机器人传感器断流或遥测连接空闲时，业务吞吐为零但单核接近满载。

**原理与容易误判的地方。** 非阻塞接口把等待策略交给调用者。不断重试仍会执行系统调用和用户循环；CPU 忙不一定代表做了有价值的计算。固定 sleep 也可能换成过大的响应延迟。
